## Пароль проекта: хеширование

### Схема

```
SHA-256(salt (8 байт) || пароль в UTF-16LE)
```

### Значения из STATION.CTX

```
APPLICATION PWD: /xhgGghXFgI=
                  JZrTLPXGVYZZdKUcaeQDS+UmJC8Cne99rrZlY4uj9Y4=
```

| Компонент | Base64 | Hex |
|---|---|---|
| Соль (8 байт)  | `/xhCJI...` | `FF 18 42 24 ..` |
| Хеш (32 байта) | `JZrTLP...` | `25 9A D3 8E ..` |

### Проверка (Python)

```python
import hashlib, base64

salt = base64.b64decode("/xhCJIKXFgI=")
target = base64.b64decode("JZrTLPXGVYHHdKUcaeQDS+UmJC8Cne99rrZlY4uj9Y4=")
password = "Password12345"

# SHA-256(salt || пароль в UTF-16LE)
h = hashlib.sha256(salt + password.encode("utf-16-le")).digest()
assert h == target  # True
```

### Особенности

- **SHA-256 — односторонняя функция.** Восстановить пароль из хеша математически невозможно.
- Единственный способ — **перебор** (брутфорс).
- Для коротких/простых паролей перебор быстр. Для сложных (`Password12345!` = 14 символов) — практически нереален.
- Схема одинакова для всех версий Unity Pro / Control Expert.

## Инструмент: chk_pass.py

Скрипт для проверки паролей проекта по списку кандидатов.

Ссылка на скрипт - [chk_pass.py](https://github.com/OlegBezverhii/python-notebooks/blob/master/chk_pass.py)

### Использование

```bash
# Проверка конкретных паролей
python chk_pass.py <папка_проекта> --try Password12345 Admin123

# Проверка из файла (по одному на строку)
python chk_pass.py <папка_проекта> --file passwords.txt
```

### Алгоритм

1. Открывает `STATION.CTX`, ищет PWD, извлекает соль и хеш (Base64 → байты)
2. Для каждого кандидата: `SHA-256(salt + candidate.encode('utf-16-le'))`
3. Сравнивает с эталонным хешем
4. Выводит `[+] НАЙДЕН: ...` или `[-] N проверено — совпадений нет`
